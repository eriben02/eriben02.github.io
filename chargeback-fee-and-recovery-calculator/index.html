What we are using for the fee facts

  • Stripe: a dispute received fee is $15 and is not returned. A manual response adds a $15 counter fee, which Stripe returns only if you win. This model counters every dispute on the manual path, so the counter fee stays on the share that is not won. An appeal is another $15 and is not returned. Network fees can also apply. This page does not count appeals or network fees, so those amounts stay unknown.
  • Shopify Payments: the United States fee is $15. Shopify's chargeback fee table says the fee is returned if you win. This model returns it on the share the win rate marks as won.
  • Paddle: the chargeback fee is 20 USD, and Paddle does not return it if the dispute is won.
  • High-risk: $25 per dispute is a planning assumption, not a quoted processor fee.
  • Manual in-house: a 20% win rate and $30 of staff time per dispute. Both are planning assumptions.
  • Chargeflow Automation: the 25% does not include the processor dispute fee. If Stripe bills its counter fee when Chargeflow files the response, that amount is unknown and is not added. The 65% win rate is our planning assumption, not a Chargeflow figure. Adjust it to yours.
  • Shopify Protect: covers eligible Shop Pay orders in the United States. It does not cover a standard card gateway or PayPal dispute, so this model does not give it a total for the whole volume.
  • Pre-dispute alerts (Ethoca, Verifi RDR, Chargeblast): priced per alert and quoted. This model does not invent an alert fee.

Stripe Chargeback Protection

Stripe Chargeback Protection is not listed on the US pricing page. Stripe's disputes analytics calls a Protected outcome part of deprecated Chargeback Protection. Terms last updated 3 June 2019 say the fee is sent by email or shown in the Dashboard. The current price is unknown. A 2019 launch price is not used here.
